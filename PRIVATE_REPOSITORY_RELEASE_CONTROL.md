# PRIVATE repository — release control
This repository holds the independently authored source audit, opt-in Colab
notebook, provenance protocol and synthetic tests as a private scholarly
reproducibility staging area. The present PI instruction explicitly authorizes
private staging/upload; public visibility is **not** authorized before paper
submission. Treat publication as a distinct change requiring PI instruction.

DO NOT commit:
- raw BCCD/BCDD microscopy images, original annotations, dataset checkouts
- private Colab run transcripts, identity-bearing receipts, passwords/tokens
- original M3 production code, M3 evidence, M4 training/clinical materials
- generated image files or ZIPs that may include original microscopy

The MIT LICENSE in this private stage documents intended open-source terms,
not a third-party dataset relicensing grant. Contributor and institutional IP
approval remain required before changing the repository to public.

Release rule: after conference submission is independently evidenced, verify
PI authorization, audit git history and branch protection, check all author
and source terms, update CFF with real paper metadata once published, then
and only then change GitHub visibility. Keep exact change receipt and commit.
