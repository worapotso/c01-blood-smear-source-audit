# Public release scope and reproducibility boundaries

This code package was released at the PI's express request on 2026-11-06.

- Released: independently authored read-only source-audit Python code, opt-in Colab notebook, synthetic tests, fixed expected values, reference protocol, source revision citations and MIT license.
- Not released: original BCCD/BCDD microscope imagery, source annotations or dataset clones, private project evidence/run receipts, M3 production code, training models or M4 workflows.
- The notebook defaults to no source download and no experiment execution. Every run requires user action, access to upstream data under upstream terms, and independent reporting of observed results.
- The manifest of 32 historical targets contains expected values, not an executed run.
- The software MIT license covers the original audit implementation, not any third-party dataset/image rights.
- The companion C-01 paper is a manuscript under preparation. Cite the actual publication only when bibliographic details are verified.
